Forge Help

Forge hosts your AI coding sessions side by side in one terminal: spawn agents, watch them work, group them so they can coordinate, and gate what they may do without asking. Everything below starts from one chord: hold Ctrl, press b, release both, then press the command key. Esc cancels a pending chord.

Start, quit & restore

Launch with forge. Quitting is a two-step handshake so you never lose work by accident:

  1. Press Ctrl-b q — a confirm modal opens (No is the default).
  2. Choose Yes (or y) — a Saving sessions… modal appears while every live agent session is snapshotted, then Forge exits.

Next launch offers the snapshot back in a restore picker: Enter relaunches each session with its resume command, Esc starts fresh. Quitting with no live sessions leaves the saved file untouched, so an old snapshot survives an empty quit.

Sessions

Creating one

Ctrl-b c opens the dialog. Fill in Directory (prefilled with the current one), Name, pick the agent Tool (Claude, Codex, Muse, …), optionally join a Group, and submit. Forge spawns the agent in a pane and focuses it.

# Example: start a docs session in ~/site with Codex
Ctrl-b c  →  Directory: ~/site  →  Name: docs  →  Tool: codex  →  Enter

Switching

  • Ctrl-b n / p steps through sessions.
  • Ctrl-b 1–9 jumps by the number shown in the bottom bar.
  • Move the fleet cursor with Ctrl-b j/k, open it with Ctrl-b Enter.
  • Click any tab, bar number, or pane to focus it with the mouse.

Tabs, grid, kill

  • Ctrl-b t flips the focused session between its agent view and a plain terminal.
  • Ctrl-b w tiles every session in a grid; repeat to return to one pane.
  • Ctrl-b x asks Are you sure you want to kill this session? — Yes leaves its groups, fails its queued work loudly, and drops it from the UI.
The bottom bar always lists ungrouped sessions first, grouped ones after. Bar numbers follow that order, so digit 1 is always the leftmost entry.

Groups

Ctrl-b g opens group management: create a group, add or remove member sessions, rename it, or delete it. Joining a group at session-creation time works too, via the dialog's Group picker.

Sessions in a group share a channel: queued peer messages deliver when a session goes idle, so a fleet can hand work to whoever finishes first.

# Example: a review fleet
Ctrl-b c  →  Name: writer   →  Group: review  →  Enter
Ctrl-b c  →  Name: checker  →  Group: review  →  Enter

Permissions

Forge gates tool calls through hooks before the harness runs them. Four modes:

ModeMeaning
OffEvery ask goes back to the harness — the agent prompts you itself.
Safe-OnlyBlock patterns first, then allow patterns and safe reads; anything else asks. A block always wins, even over a matching allow.
YOLOEverything is allowed without asking.
AI-AssistedReserved for a judging classifier; currently asks like Off.

Ctrl-b y flips between Off and YOLO, and the sidebar Off/Yolo buttons set those two directly with the mouse or keyboard. Safe-Only and AI-Assisted are config-file only: set mode (one of off, safe-only, ai-assisted, yolo) plus allow/block patterns in ~/.forge/config.toml under [permission]. Every verdict is appended to ~/.forge/audit.log (owner-only).

# Example: let listings through, never deletions
[permission]
mode = "safe-only"
allow = ["^ls", "^git status"]
block = ["^rm -rf"]

Telegram

Ctrl-b m opens Telegram settings: paste your bot token, allowlist your user id, enable delivery, save. Forge then forwards session output and attention pings to your phone; reply to a message natively (or with [name]) to message that session back. The sidebar shows delivery state (on, retrying, failed) so a dead token never fails silently.

Themes

Ctrl-b e opens the theme picker over the builtin default plus every valid theme.json under ~/.forge/themes. Drop a file there to add your own — broken files warn and are skipped, never hiding the rest. The choice persists across restarts.

Restore in detail

The quit snapshot records each live agent session: name, tool, working directory, groups, and the harness conversation id. Restoring relaunches each with its resume command and rejoins its groups. Entries whose directory vanished are skipped with a reason instead of failing the batch, and quitting twice with the same layout refreshes the newest entry rather than stacking duplicates.

Mouse & paste

  • Click top-bar tabs, session-bar numbers, sidebar rows, and dialog buttons — every keyboard action has a mouse twin.
  • An open modal owns the mouse: clicks behind it do nothing.
  • Pasting into a pane uses bracketed paste when the pane wants it, so multiline text lands intact.

Sidebar & fleet

The sidebar shows the focused session's detail (tool, directory, state, status) above the fleet: every session with its attention state. Idle sessions queue peer messages and timer pings; twenty silent minutes marks you away to every live session, and your next keystroke announces the return.

Command line

Beyond the TUI, the forge binary registers itself with agent CLIs and serves their hooks:

forge --version | --help
forge hook-relay [endpoint]   # one hook event from stdin; always exits 0
forge mcp-serve               # JSON-RPC comms server on stdio
forge install-hooks | install-mcp | install-skills
forge uninstall-hooks | uninstall-mcp | uninstall-skills
forge install-codex|gemini|metamate   # full per-harness setup

Troubleshooting

No browser opened

Help opens via xdg-open. If nothing appears, open /tmp/forge-help.html yourself — Forge rewrites it on every Ctrl-b h, so it is always current.

A session wedged after its first tool call

That is the turn-end edge missing: Forge tracks turn state through the Stop hook. Re-run forge install-hooks and restart the session.

Restore offers a stale entry

Pick it and let missing directories skip, or quit empty once with the picker dismissed — empty quits never clobber saved entries.
